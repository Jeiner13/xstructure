xStructure — archivos de la página web

Contenido:
- index.html: estructura principal de la página.
- styles/styles.css: estilos, colores y diseño responsive.
- scripts/header.js: menú móvil y año automático del pie.
- assets/: logo recortado y emblema decorativo.

Cómo usar:
1. Descomprime la carpeta.
2. Abre index.html en tu navegador o usa Live Server en VS Code.
3. Reemplaza el correo de ejemplo contacto@xstructure.com por el correo oficial.
4. Sustituye las imágenes y textos de proyectos de ejemplo por trabajos reales.
5. Las fotografías remotas requieren conexión a internet.

Nota:
Se mantiene una combinación de azul oscuro, morado y fondos claros. El emblema del pie es decorativo y opcional.
